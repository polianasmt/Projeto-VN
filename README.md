# 🐾 The Cat Beyond the Window

Um pequeno projeto de visual novel/otome desenvolvido em **Ren'Py**, criado como estudo de engine, narrativa interativa e organização de assets para jogos narrativos.

> “O que existe além da janela?”

## 🌙 Sobre o projeto

**The Cat Beyond the Window** é uma visual novel com atmosfera romântica, delicada e levemente misteriosa.  
O projeto acompanha uma protagonista em seus primeiros encontros com **Ryu**, um personagem enigmático com traços felinos e uma presença calma, charmosa e um pouco suspeita.

Este repositório foi criado principalmente para estudar:

- estrutura básica de projetos em Ren'Py;
- criação de diálogos;
- sprites e expressões de personagens;
- side images;
- personalização de menu;
- organização de arquivos;
- construção de uma pequena experiência jogável.

## Personagens

### Ryu

Ryu é um personagem de aparência delicada e misteriosa, com cabelos claros, olhos verdes e traços felinos.  
Ele possui uma personalidade calma, provocadora e difícil de interpretar.

### Protagonista

A protagonista é a personagem principal da visual novel.  
Ela aparece como side image durante os diálogos e será usada para testar expressões, emoções e reações durante a narrativa.

## Como executar
1. Baixe e instale o Ren'Py.
2. Clone este repositório:
git clone https://github.com/seu-usuario/seu-repositorio.git
3. Abra o Ren'Py Launcher.
4. Selecione a pasta do projeto.
5. Clique em Launch Project.
